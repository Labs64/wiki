Glossary
=======================================

<table>
<colgroup>
<col style="width: 50%" />
<col style="width: 50%" />
</colgroup>
<tbody>
<tr class="odd">
<td><p><strong>API key</strong></p></td>
<td><p markdown="1">A credential that lets software call the NetLicensing API on your behalf without your password. Each key has a role, from Licensee (validation only) to Admin, see [API Security](security#api-key-identification).</p></td>
</tr>
<tr class="even">
<td><p><strong>Client</strong></p></td>
<td><p>In the context of data communication with NetLicensing, e.g. via RESTful NetLicensing API, the client is the program sending requests to NetLicensing and receiving answers from NetLicensing.</p></td>
</tr>
<tr class="odd">
<td><p><strong>Entity</strong></p></td>
<td><p markdown="1">Instance of an object within [NetLicensing Object Model](object-model)</p></td>
</tr>
<tr class="even">
<td><p><strong>Floating session</strong></p></td>
<td><p markdown="1">One seat of a [Floating](floating) license in use. Your application checks a session out when work starts and checks it in when it ends; unused sessions are released after the maximum checkout validity.</p></td>
</tr>
<tr class="odd">
<td><p><strong>Grace period</strong></p></td>
<td><p markdown="1">Extra time after a [Subscription](subscription) ends during which the customer can keep using the product while they renew.</p></td>
</tr>
<tr class="even">
<td><p><strong>License</strong></p></td>
<td><p>License is the object of purchase, owned by a Licensee, and influences the resulting state of the product (validation result). Licenses are created based on License Templates.</p></td>
</tr>
<tr class="odd">
<td><p><strong>License Template</strong></p></td>
<td><p>License Template is a configuration element, that doesn't belong to and Licensee, but acts as a license prototype.</p></td>
</tr>
<tr class="even">
<td><p><strong>Licensee</strong></p></td>
<td><p>Holder of licenses. This can be an individual or organisation, but not necessarily the end-user.</p></td>
</tr>
<tr class="odd">
<td><p><strong>Licensee auto-create</strong></p></td>
<td><p markdown="1">Product setting that makes NetLicensing create a licensee automatically the first time an unknown licensee number is validated together with the product number, see [How do I create customers automatically?](faq-licensee-auto-create)</p></td>
</tr>
<tr class="even">
<td><p><strong>Licensee number</strong></p></td>
<td><p markdown="1">The unique ID of a licensee. Your application sends it on every validation. It can be generated by NetLicensing or chosen by you, for example a customer or installation ID.</p></td>
</tr>
<tr class="odd">
<td><p><strong>Licensing Model</strong></p></td>
<td><p>Set of algorithms, rules and constraints applied to the licenses and license templates that define interconnection between licenses and possible states of the product or product module.</p></td>
</tr>
<tr class="even">
<td><p><strong>MCP (Model Context Protocol)</strong></p></td>
<td><p markdown="1">Open standard for connecting AI assistants to tools. The [NetLicensing MCP server](netlicensing-mcp) lets AI agents manage licenses.</p></td>
</tr>
<tr class="odd">
<td><p><strong>NetLicensing</strong></p></td>
<td><p>Labs64 NetLicensing, a cloud service for managing software licenses (Licensing-as-a-Service).</p></td>
</tr>
<tr class="even">
<td><p><strong>NetLicensing Agent</strong></p></td>
<td><p markdown="1">On-premises server that answers validation requests in networks without internet access, see [NetLicensing Agent](netlicensing-agent).</p></td>
</tr>
<tr class="odd">
<td><p><strong>NetLicensing API</strong></p></td>
<td><p>Network API of NetLicensing.</p></td>
</tr>
<tr class="even">
<td><p><strong>NetLicensing Management Console</strong></p></td>
<td><p><a href="https://ui.netlicensing.io" class="external-link">Web-based user interface</a> of NetLicensing, accessible by vendor.</p></td>
</tr>
<tr class="odd">
<td><p><strong>NetLicensing Shop</strong></p></td>
<td><p>Web Frontend (eCommerce) of NetLicensing for end users, used to shop for new licenses.</p></td>
</tr>
<tr class="even">
<td><p><strong>Node secret</strong></p></td>
<td><p markdown="1">A value that identifies a device or user in the [Node-Locked](node-locked) model, usually a hardware fingerprint generated by your application.</p></td>
</tr>
<tr class="odd">
<td><p><strong>Number,</strong><br />
<strong>Business Number,</strong><br />
<strong>Entity Number,</strong><br />
<strong>External Number,</strong><br />
<strong>Identification Number</strong></p></td>
<td><p>Arbitrary sequence of printable ASCII characters that uniquely identify an object within NetLicensing. E.g. Licensee number can be something like <code>'CUST-0015'</code></p></td>
</tr>
<tr class="even">
<td><p><strong>Offline validation file</strong></p></td>
<td><p markdown="1">A signed validation result for one licensee that your application can check without a connection, see [Offline License Validation](offline-license-validation).</p></td>
</tr>
<tr class="odd">
<td><p><strong>Product</strong></p></td>
<td><p>Generalized term, meaning any product or service that is integrated with NetLicensing and is subject of licensing to licensees.</p></td>
</tr>
<tr class="even">
<td><p><strong>Product Module</strong></p></td>
<td><p>In terms of NetLicensing, every product consists of one or more product modules that are licensed independently of each other. This ensures high degree of NetLicensing customizability.</p></td>
</tr>
<tr class="odd">
<td><p><strong>PSP,</strong><br />
<strong>Payment Service Provider</strong></p></td>
<td><p>Service used by NetLicensing for collecting payments from end customers, such as PayPal.</p></td>
</tr>
<tr class="even">
<td><p><strong>Shop token</strong></p></td>
<td><p markdown="1">Short-lived token that opens a NetLicensing Shop session for a customer; created with the [token service](token-services#create-token).</p></td>
</tr>
<tr class="odd">
<td><p><strong>Token</strong></p></td>
<td><p>Unique identifier randomly generated on demand, that is valid for a limited period of time and/or for limited number of uses (e.g. one-time use) after generation. Used for secure access to NetLicensing resources via unique non-predictable URLs.</p></td>
</tr>
<tr class="even">
<td><p><strong>Transaction</strong></p></td>
<td><p>Any particular action within NetLicensing that cause change in licenses (adding, removing, modification) is a transaction and is accompanied by the corresponding transaction record.</p></td>
</tr>
<tr class="odd">
<td><p><strong>TTL (time-to-live)</strong></p></td>
<td><p markdown="1">Timestamp in every validation response that says how long the result may be reused before validating again.</p></td>
</tr>
<tr class="even">
<td><p><strong>Validation</strong></p></td>
<td><p>Specific request to NetLicensing via NetLicensing API, typically made by a product, to obtain the current licensing state of a specific licensee.</p></td>
</tr>
<tr class="odd">
<td><p><strong>Vendor</strong></p></td>
<td><p>Vendor uses NetLicensing by integrating it to his product or service. This is You, NetLicensing customer.</p></td>
</tr>
<tr class="even">
<td><p><strong>Warning level</strong></p></td>
<td><p markdown="1">GREEN, YELLOW or RED indicator of whether a customer is fully licensed or close to becoming under-licensed, see [Warning Level](warning-level).</p></td>
</tr>
</tbody>
</table>
